# E-Commerce Sales Analysis

## 📌 Project Overview

This is an end-to-end Data Analytics project focused on analyzing e-commerce sales data.

The project covers the complete data analytics workflow, starting from raw/dirty data cleaning to data analysis and interactive dashboard creation.

The main objective is to identify sales trends, profitable products, customer behavior, payment methods, order status, and city-wise sales performance.

---

## 🎯 Objectives

- Clean and preprocess raw e-commerce data
- Perform exploratory data analysis
- Analyze sales and profit performance
- Identify top-performing products and categories
- Analyze different payment methods
- Analyze order status
- Understand city-wise sales performance
- Create an interactive Power BI dashboard
- Generate useful business insights from the data

---

## 🗂️ Dataset

The dataset contains e-commerce order information such as:

- Customer Name
- Category
- Product
- Sales
- Profit
- Quantity
- Payment Mode
- Order Status
- City
- State
- Order Date
- Delivery Date
- Other order-related information

## 🔄 Project Workflow

### 1. Data Collection

The raw e-commerce dataset was collected and inspected to understand its structure, columns, data types, and missing values.

### 2. Data Cleaning

Data cleaning was performed using Excel and Python.

The process included:

- Handling missing values
- Removing duplicate records
- Correcting data types
- Standardizing column values
- Checking inconsistent data
- Preparing data for analysis

### 3. Feature Engineering

Additional useful columns were created from the existing data to support analysis and visualization.

Examples include:

- Month
- Year
- Profit-related calculations
- Order-related metrics

### 4. SQL Analysis

The cleaned data was imported into MySQL for further analysis.

SQL queries were used to analyze:

- Total sales
- Total profit
- Orders
- Product performance
- Category performance
- Payment methods
- Order status
- City-wise sales
- Monthly sales trends

### 5. Power BI Dashboard

An interactive Power BI dashboard was created to present the key findings.
